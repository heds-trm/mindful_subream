This folder contains the default {roi_size}mm images.
Each lesion may contain more than one point, resulting in the following naming convention: 
	[patient-id]_lesion_[lesion-index]_[point_index]_[short_label]

Additionaly, all 13 (sub) phases were extracted for each ROI.
Therefore, each folder in this folder contains 13 images, 1 per phase.
