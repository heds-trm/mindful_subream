# Mindful SUBREAM examples

Currently, the following examples are available:
- [MURA](./mura/MURA_README.md): extension of the [MURA example](https://github.com/heds-trm/mindful_core/blob/main/examples/mura/MURA_README.md) found in Mindful-core by adding multimodality support.
- [Lesion Lens](./gc_samples/README.md): explains how to prepare a sample to be uploaded to the [Lesion Lens algorithm](https://grand-challenge.org/algorithms/subream-breast-mri-lesion-lens/) hosted on the Grand-Challenge platform.
- [4D UF](./4duf/4DUF_README.md): presents configuration files to test the various 4D models to characterize breast lesions in Ultrafast DCE MRI (work in progress).
