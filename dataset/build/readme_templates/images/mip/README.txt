This folder contains the MIP images extracted from {roi_size}mm images.
Each lesion may contain more than one point.
In addition, each images were augmented {mip_augmentation_count} prior to the ROI extraction.
This results in the following naming convention: 
	[patient-id]_lesion_[lesion-index]_[point_index]_[short_label]_version_[augmentation_index].mha
